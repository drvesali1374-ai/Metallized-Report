# 🏭 سامانهٔ مانیتورینگ صنعتی رول‌ها

وب‌اپلیکیشن **کاملاً آفلاین** برای مانیتورینگ رول‌های تولید صنعتی — بدون نیاز به هیچ سرور، اینترنت، Node.js یا نصب هرگونه نرم‌افزار.

> کافی است روی فایل `index.html` **دابل‌کلیک** کنید تا در مرورگر اجرا شود.

---

## 📁 ساختار پوشه‌ها

```
roll-monitor/
├── index.html          ← فایل اصلی برنامه (دابل‌کلیک برای اجرا)
├── app.js              ← منطق برنامه (محاسبات، فرم‌ها، ایمپورت اکسل)
├── style.css           ظاهر برنامه (تم تیره، راست‌چین، واکنش‌گرا)
├── README.md           ← همین راهنما
└── lib/                ← کتابخانه‌ها (همه لوکال — بدون CDN)
    ├── dexie.min.js        ← مدیریت IndexedDB
    ├── xlsx.full.min.js    ← خواندن فایل‌های اکسل (SheetJS)
    └── fonts/
        ├── Vazirmatn-Regular.woff2
        ├── Vazirmatn-Medium.woff2
        └── Vazirmatn-Bold.woff2
```

---

## ✨ امکانات

| بخش | توضیح |
|---|---|
| **ورود داده‌ها** | ایمپورت `rolls.xlsx` (رول‌های موجود) و `Archived Rolls.xlsx` (سابقه) با کشیدن‌ورهاکردن یا انتخاب فایل |
| **رول‌های ستاپ** | ثبت رکوردهای ستاپ با فیلدهای: شماره ستاپ، شماره دستگاه، عرض رول، نوع رول، تعداد رول |
| **داشبورد** | چهار شاخص بلادرنگ: رول خام، رول متالایز، کل رول ستاپ‌ها، رول برش‌نشده |

### منطق محاسبهٔ شاخص‌ها

1. **رول‌های خام** = تعداد ردیف‌های `rolls.xlsx` که حرف دومِ «نوع فیلم» آن‌ها `R` باشد (مانند `FRN21`، `KRN21`)
2. **رول‌های متالایز شده** = تعداد ردیف‌های `Archived Rolls.xlsx` که حرف دومِ «نوع فیلم» آن‌ها `R` باشد
3. **کل رول‌های ستاپ‌ها** = مجموع ستون «تعداد رول» از تمام رکوردهای ثبت‌شده در پنل «رول‌های ستاپ»
4. **رول‌های برش‌نشده** = کل ستاپ‌ها − (رول‌های خام + رول‌های متالایز)

```js
// شرط تشخیص (دقیقاً همین پیاده‌سازی شده):
filmType && filmType.length >= 2 && filmType.charAt(1).toUpperCase() === 'R'
```

## 💾 محل ذخیرهٔ داده‌ها

تمام داده‌ها فقط و فقط در **پایگاه‌دادهٔ داخلی مرورگر شما (IndexedDB)** ذخیره می‌شود:
- هیچ داده‌ای به هیچ سروری ارسال نمی‌شود (حتی یک بایت).
- با بستن مرورگر، داده‌ها باقی می‌مانند و در اجرای بعدی بازیابی می‌شوند.
- داده‌های هر مرورگر/کامپیوتر جداگانه است.

> ⚠️ اگر داده‌های «Site Data» مرورگر را پاک کنید، رکوردهای ستاپ و فایل‌های ایمپورت‌شده نیز حذف می‌شوند.

## 🔄 راهنمای دستی قرار دادن کتابخانه‌ها در پوشهٔ `lib`

اگر فایل‌های کتابخانه را از دست دادید یا می‌خواهید آخرین نسخه را جایگزین کنید:

### گام ۱ — دانلود SheetJS
در مرورگر این آدرس را باز کنید و با `Ctrl+S` فایل را ذخیره کنید:
- **آدرس:** `https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js`
- **نام ذخیره:** دقیقاً `xlsx.full.min.js`

### گام ۲ — دانلود Dexie.js
- **آدرس:** `https://unpkg.com/dexie@4.0.8/dist/dexie.min.js`
- **نام ذخیره:** دقیقاً `dexie.min.js`

### گام ۳ — دانلود فونت وزیرمتن (اختیاری)
- `https://cdn.jsdelivr.net/gh/rastikerdar/vazirmatn@v33.003/fonts/webfonts/Vazirmatn-Regular.woff2`
- `https://cdn.jsdelivr.net/gh/rastikerdar/vazirmatn@v33.003/fonts/webfonts/Vazirmatn-Medium.woff2`
- `https://cdn.jsdelivr.net/gh/rastikerdar/vazirmatn@v33.003/fonts/webfonts/Vazirmatn-Bold.woff2`

### گام ۴ — قرار دادن فایل‌ها
ساختار نهایی باید این‌گونه باشد (نام فایل‌ها **دقیقاً** همین باشد):

```
roll-monitor/
├── index.html
├── app.js
├── style.css
└── lib/
    ├── dexie.min.js         ← فایل گام ۲
    ├── xlsx.full.min.js     ← فایل گام ۱
    └── fonts/
        ├── Vazirmatn-Regular.woff2   ← فایل‌های گام ۳
        ├── Vazirmatn-Medium.woff2
        └── Vazirmatn-Bold.woff2
```

✅ حالا دوباره روی `index.html` دابل‌کلیک کنید — برنامه باید بدون هیچ خطایی اجرا شود.

> 💡 در صورت نبود فایل‌های فونت، برنامه با فونت جایگزین (Tahoma) اجرا می‌شود؛ اما نبود `dexie.min.js` یا `xlsx.full.min.js` با پیام خطای واضح اعلام می‌شود.

## 🚀 نحوهٔ اجرا

1. پوشهٔ `roll-monitor` را هرجا دوست دارید کپی کنید (مثلاً دسکتاپ).
2. روی `index.html` دابل‌کلیک کنید.
3. مرورگرهای پیشنهادی: **Chrome**، **Edge** یا **Firefox** (نسخه‌های به‌روز).

### اولین استفاده
1. به تب **«ورود داده‌ها»** بروید و دو فایل `rolls.xlsx` و `Archived Rolls.xlsx` را ایمپورت کنید.
2. به تب **«رول‌های ستاپ»** بروید و رول‌های هر ستاپ را ثبت کنید.
3. تب **«داشبورد»** به‌صورت بلادرنگ چهار شاخص را نشان می‌دهد.
